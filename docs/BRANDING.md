# PurpleMagic brand assets

The project owner supplied `Purple-brand-icons-20261020.zip` for the launcher, GM Console and repository branding.

- **witch**: repository header, GM brand mark, launcher header/login panel, and Windows executable icons.
- **hat**: GM browser favicon, with PNG and multi-resolution ICO formats.

The PNGs preserve their transparent backgrounds and original aspect ratios. Windows icons retain the supplied size variants. [The asset manifest](brand-assets.json) records the source archive and exact file hashes.

The accepted orchid glass layout and themes continue unchanged. The branding override lives in `gm-console/src/brand.css`; the frozen design styles remain the original baseline.
