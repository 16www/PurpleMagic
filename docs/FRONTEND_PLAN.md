# PurpleMagic 前端重构分区

保留已认可的 侧栏导航、页面布局和主题调色。下一轮调整重点是页面职责和完整操作路径。本文件为功能布局方案，当前网页源码保留现状。

| 一级入口 | 页面与核心操作 | 对应台账 |
| --- | --- | --- |
| 玩家 | 账号/角色检索；进入独立玩家详情页，固定显示当前账号与角色身份 | GM-01～09、41、46 |
| 玩家详情·资产 | 账号点券、角色金币、账号金库、共享晶块；各自余额、变更、流水 | GM-02、14 |
| 玩家详情·物品 | 背包、穿戴、个人仓库、金库分容器；列表与右侧实例详情；配置/删除/发放/批次选择 | GM-10～16、33 |
| 玩家详情·游戏任务 | 已接/可交/已完成；任务库检索；预览变更、完成与重置、批处理结果 | GM-22～27 |
| 玩家详情·成长 | 等级、职业/觉醒、副职业、SP/TP、契约、容量；各自表单和记录 | GM-03、05～09 |
| 玩家详情·邮箱 | 邮件筛选、正文/附件、删除、跨页清理；发邮件打开统一投递表单 | GM-17～19 |
| 发放与福利 | 单人/指定名单/在线名单；一次性发放与长期福利分开；规则按账号或角色去重 | GM-16、18～20 |
| 运营作业 | 邮件、福利、清理的批次进度、失败项、暂停/继续、回执；后续扩展索引和快照 | GM-21 |
| 治理与调查 | 封禁/IP限制、在线会话、通关记录、异常规则/白名单、人工复核 | GM-29～34、42～45 |
| 内容与更新 | 登录器公告、更新源、版本、索引代次与构建结果、兼容profile | GM-15、23、35、37、38、47 |
| 系统与审计 | 管理身份权限、连接策略、维护、备份、跨功能审计；游戏通知单独标收件范围 | GM-28、36、39、40、48 |

角色详情使用可直接导航的完整页面，避免把所有功能塞进一层大弹窗。账号共享资产与角色资产分区，并在每次提交处显示实际目标。任务页使用“游戏任务”和“运营作业”两个明确名称。

读操作只触发当前页面需要的范围，支持分页、筛选、取消旧请求和主动刷新。物品实例详情同时展示“玩家持有值”和“PVF定义”；表格选中、跨页作业、全量扫描分别提供清晰的范围选择。

写操作统一呈现目标、前后值、影响范围、原因与操作结果；按现有接口显示预览/提交/恢复。不同功能保留领域校验与独立回执，前端不拼接SQL。正在开发或接口未接入的功能在功能台账中排期，页面只提供当前可执行的操作。

优先实现：玩家详情的完整资产/物品/任务工作区 → 邮件福利与作业 → Hub公告会话统一 → 治理调查及系统工具。PWA和Android复用同一套管理API，另列客户端适配任务。
