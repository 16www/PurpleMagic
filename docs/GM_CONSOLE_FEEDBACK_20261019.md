# 兰紫 GM 实测反馈修正

七张实测图对应加载反馈、数值输入、删除入口、时装字段、在线筛选、ID 替换与装备强化。

- 页面标题加载圈按并发读取计数；背包完整读取期间保留列表加载态。数值表单保留字符串草稿，允许清空重填。
- SP / TP 显示剩余、总量、已用及当前等级基准。`reset_defaults` 在同一事务清除两种额外点数，按批准 PVF 重算总量并扣除已用点数；保留已学技能。已用超过等级基准时返回现有 spent 错误。
- 列表摘要标记 revisionScope=summary；操作先核对所见 ID/数量/绑定，再取得完整实例修订生成预览，避免摘要哈希与完整写修订混用。
- 单件删除在详情末尾，批量删除在列表上方；沿用现有选中实例修订、一次确认和永久回执。
- 时装不从 0x0A 等复用字节投影装备强化、增幅或锻造。普通装备完整开放服务端能力中的 0–31 强化范围，低 5 位存储上限来自本服写入器。
- `characters?online=online|offline` 使用完整运行态快照，在每个数据库分片分页之前筛选；游标绑定状态筛选。账号范围页面保留完整账号角色列表的筛选。
- `inventory-operations` 的 configure/options.itemId 支持单个同类实例替换，保留数量、实例属性、绑定与期限。PVF 类型/部位/存储种类匹配后更新数据库 ItemID 与 119 字节行中的 ID；穿戴实例同步写 Equipment。宠物关联和账号固定计数使用专门契约。预览绑定原修订、PVF、目标 ID；写入和回执同事务，重试幂等。

验证：26 项前端测试；一次性 MariaDB 单/双分片覆盖 ID 替换（含穿戴）、回滚、重试/修订冲突、SP/TP 默认值与技能保留、完整在线分页；全量回归首次两处测试夹具修正后，相关回归复跑通过。公开检查入口见 [验证说明](../gm-console/design-qa.md)；环境回执单独保存。
