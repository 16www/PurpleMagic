角色详情使用可直接导航的完整页面，避免把所有功能塞进一层大弹窗。账号共享资产与角色资产分区，并在每次提交处显示实际目标。任务页使用“游戏任务”和“运营作业”两个明确名称。

读操作只触发当前页面需要的范围，支持分页、筛选、取消旧请求和主动刷新。物品实例详情同时展示“玩家持有值”和“PVF定义”；表格选中、跨页作业、全量扫描分别提供清晰的范围选择。

写操作统一呈现目标、前后值、影响范围、原因与操作结果；按现有接口显示预览/提交/恢复。不同功能保留领域校验与独立回执，前端不拼接SQL。正在开发或接口未接入的功能在功能台账中排期，页面只提供当前可执行的操作。

优先实现：玩家详情的完整资产/物品/任务工作区 → 邮件福利与作业 → Hub公告会话统一 → 治理调查及系统工具。PWA和Android复用同一套管理API，另列客户端适配任务。
