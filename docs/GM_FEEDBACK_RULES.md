# GM 批量发放与编辑规则

2026-10-18 候选实现。GM Web 与私有 v1 API 共用以下规则；外部服务实现见[服务分工与运行](GM_EXTERNAL_SERVICES.md)。

| 操作 | 页面行为 | 服务端约束 |
| --- | --- | --- |
| 勾选账号发道具 | 账号／角色表支持复选、选本页、清空；选择可跨查询页保留 | 每个账号展开为其全部现有角色，与显式角色合并去重；最多100个账号、100个显式角色、最终5000个角色 |
| 一次邮件 | 选择对象、填写道具后点击发送，只确认一次；展示最终完整角色名单 | 后台准备固定名单，确认后每批10人连续执行；同一草稿请求键固定角色、创建时间和奖励 |
| 福利规则 | 保存后启用即可自动发放；未来角色是独立选项 | 后台扫描按规则ID和账号／角色永久回执去重，刷新或关闭网页不影响扫描 |
| 角色资产编辑 | 目标角色返回选角界面并完成清理即可 | 验证目标角色的选角准入、在线及清理状态；同账号其他角色不阻断 |
| 账号共享资产 | 账号金库、共享晶块／灵魂仍需账号退出 | 使用账号级准入保护；点券和普通邮件分别沿用其权威事务 |
| PVF 索引 | 使用批准PVF对应的索引代次 | 完整SHA256匹配才可复用；只改时间不失效，内容改变即拒绝旧索引并重建 |

## 发放与恢复

`POST /api/v1/mail/preview`新增`accountIds`，保留`recipients`和原附件字段。账号排序后参与内容指纹；同一请求键内容变化返回冲突。展开在幂等创建事务内部完成，已有任务直接读回固定名单，不纳入后来新建角色。不存在角色的账号不产生收件人；最终名单为空则返回错误。

`GET /api/v1/tasks/{id}/confirmation`返回任务摘要及完整的`accountId / characterId / name`名单。读取失败或任务修订变化时，确认按钮保持禁用；重新打开后读取最新名单。确认后的`POST /tasks/{id}/run`继续使用原revision、固定名单及永久回执。

外部模式下，一次邮件确认后进入持久队列；关闭网页后继续分批，重启或响应丢失后读取原回执恢复。任务记录可查看进度、暂停及重试失败项。兼容本地模式保留浏览器逐批推进。

## 自动福利与旧规则

新版`POST /api/v1/benefits/{id}/state`启用时调用`EnableAutomaticCampaign`。首次自动纳入现有角色的截止时间保存在`ExistingThrough`；暂停／恢复保留该时间、原`FirstEnabledAt`、规则ID和全部回执。`AutoNewCharacters`控制后续新建角色的资格。只发给现有角色的规则如需扩大人群，应新建规则。

读取旧的已启用规则不会自动扩大受众。旧规则明确通过新版启用时才纳入当时已有角色；已获得奖励的对象继续由原回执去重。账号级规则仍每账号一次，沿用已有收件角色选择策略；选择账号的一次邮件则发给该账号的全部现有角色，两者语义分开。

停用等待在途批次结束。删除邮件不删除发放回执。PVF变更仍先核对长期附件规则的差异，沿用原规则ID；不以重建索引或迁移主机为理由创建替代规则。

## PVF 代次

`DiskArchive.OpenDisk`核对PVF完整SHA256、索引格式及记录；路径、大小、修改时间不能替代hash。内容变化后，使用批准的新文件离线构建并核验新代次，再切换管理服务配置。运行服务绑定启动时的代次，禁止原地覆盖正在使用的文件。

PVF、完整索引和静态查询在外部 GM 服务运行；启动时校验完整摘要。代次变化后生成并验证新索引，再切换服务配置。

## 验证入口与替换依赖

- `gateway/internal/services/gmtool/api_v1_feedback_test.go`：一次性MySQL单／双分片，账号展开去重、固定名单、实际投递、自动现有角色、未来角色、停用恢复及旧规则迁移。
- `scripts/verify_gm_feedback.py`：隔离HTTP／数据库页面验证、跨账号隔离、一次确认多批、响应丢失恢复、自动福利和明暗／手机布局。
- `gateway/internal/services/gmtool/character_edit_test.go`与游戏候选测试：协议、身份、占用范围及准入等待；详见[编辑并发保护](GM_EDIT_CONCURRENCY.md)。
- `gateway/internal/platform/pvf/disk_hash_identity_test.go`：仅时间变化可复用；相同路径／大小／时间下内容变化拒绝旧索引。

外部管理服务、PVF索引与邮件／福利调度已实现。游戏侧外部模式保留类型化操作、准入、事务及回执，详见[外部服务](GM_EXTERNAL_SERVICES.md)。
