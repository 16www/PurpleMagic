# PVF 物品详情与持久索引

物品目录的“详情”展示完整效果说明、物品故事、适用职业、满品级基础属性、使用条件和套装效果。重复字段、触发条件与技能规则保留原顺序和嵌套关系，可展开查看；基础属性只使用物品顶层字段，套装基础加成只使用相应件数块的顶层字段。

说明来自物品自己的 PVF 文档。详细效果直接展开，简要效果折叠保留；`%%` 还原为 `%`，换行保留。暂未命名的字段使用 PVF 原名。物品详情和套装详情共用当前加载的 PVF 摘要。

## 三层索引

| 索引 | 内容 | 读取方式 |
| --- | --- | --- |
| PVF 磁盘目录 | 归档路径到数据块的位置 | 按路径随机读取，有界目录/文本/解压缓存 |
| `itemIndexPath` | ID、名称、分类、等级、全部适用职业等摘要 | 启动加载，列表分页查询 |
| `item-details-v3-<sha256>.bin` | 描述、属性、条件字段和引用套装 | 固定记录表二分查找，仅解压所选物品 |

详情文件位于 `itemIndexPath` 所在目录，按 PVF SHA256 和解析版本区分。生成时逐件解析、压缩写入，完成后原子更名。每件记录有摘要校验和解压大小上限，详情正文保留在磁盘。

## 离线准备

从 `gm/` 执行，Linux 使用相应 `dist/linux-amd64/DNF90GM` 路径：

```text
dist/windows-amd64/DNF90GM.exe --config runtime/gm.json --build-pvf-index
dist/windows-amd64/DNF90GM.exe --config runtime/gm.json --build-item-details
```

第一条为新 PVF 建立归档目录；已有匹配目录时，直接执行第二条。详情生成会准备物品摘要，使用当前配置中的 PVF、摘要和索引路径，完成后退出。整个过程只读取资产并写入索引文件。

再次执行 `--build-item-details` 会校验并复用已有文件。PVF 内容或解析版本变化后生成新一代索引；旧文件可供旧 PVF 配置回退使用。本次摘要格式升为 6，补齐多职业解析，新版会重建旧格式摘要。

运行时优先读取已生成的详情索引。文件缺失或所选记录校验失败时，按需解析当前物品及其引用套装。页面空闲时没有查询或索引重建任务。

## 查询接口

`GET /api/v1/items/{itemId}` 沿用 GM 会话鉴权及 v1 响应格式，物品 ID 为规范十进制字符串。

| `data` 字段 | 内容 |
| --- | --- |
| `item` | 物品标识、名称、目录信息、全部适用职业及绑定类型 |
| `texts` | 按类型组织的完整描述与物品故事 |
| `attributes` | 满品级基础属性展示值 |
| `sections` | 有序字段，含原名、显示名、值和子段 |
| `equipmentSet` | 套装名称、件数加成及字段结构 |
| `pvfChecksum` | 本次资料对应的 PVF SHA256 |

返回码：400 参数无效，401 会话过期，404 物品不在当前目录，503 目录或详情暂不可用。物品列表继续使用分页摘要接口。

## 本地验证与预览

回归覆盖多职业、重复段、条件属性隔离、套装层级、PVF 更换、文件损坏、取消操作与索引复用。真实 PVF 全量生成覆盖 149,574 件物品，另验证分布查找、八件样本与原文解析一致、浏览器交互和移动主题。

本机隔离样本的详情索引约 197.5 MiB，800 次单件读取约 429 ms，摘要/PVF 读取器保留后的 Go 堆约 139.6 MiB；测量对象为索引读取测试进程。环境回执位于 `runtime/verification/item-details/`。

已有本地样本文件时，可运行：

```text
python scripts/preview_console.py --port 8766 --item-details runtime/verification/item-details/preview-items.json
```

打开 `http://127.0.0.1:8766/?pvf=1#items`，使用同一详情组件查看本地 PVF 样本。提取内容和生成的索引保存在忽略目录。
