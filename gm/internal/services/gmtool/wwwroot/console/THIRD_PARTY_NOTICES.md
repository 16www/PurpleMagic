# Frontend reference and attribution

The console is an original GM workflow prototype using CPA-Manager-Plus as its
visual reference. The theme runtime is adapted from the user's Theme Studio.
Pinned sources and file digests are in `reference-manifest.json`.

- **CPA-Manager-Plus**, copyright (c) 2026 Seakee. MIT, retained in

  Source: https://github.com/seakee/CPA-Manager-Plus/tree/9d719fc8cca362f7b56d294a2ad056ae99cfeba6
  The surface/color tokens, collapsible sidebar, header and compact card layout
  inform the console design.
- **cpamp-theme-studio**, copyright (c) 2026 Cec1c. MIT, retained in
  [vendor/THEME_STUDIO_LICENSE.txt](vendor/THEME_STUDIO_LICENSE.txt).

  `assets/loader.js` is adapted into `vendor/theme-studio.js`: same-window host,
  static local font URLs, independent storage keys, system-font default, console
  wording, readable custom-accent foregrounds and dark surfaces, inert background.

  Unmodified regular and semibold WOFF2 files are included under the SIL Open Font

records are synthetic.
