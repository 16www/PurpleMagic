2026-10-19 用户确认此版布局与视觉为后续 GM 实现及独立论坛项目的参考，并授权记入长期记忆。论坛 Agent 从本目录取用视觉材料，论坛业务与 GM 管理 API 各自独立。

## 必须保留的视觉特征

左侧悬浮玻璃导航，距窗口12px、宽212px、16px圆角；右侧胶囊顶栏；内容区持续身份/上下文条；胶囊页签；主列表与右侧详情面板。正文以13–14px为主，元信息11–12px，标题清晰。保留有密度的工作区，不堆叠装饰指标卡。移除无用途的工作区/服务器切换。

主色是稍偏粉的兰紫：深色 `#d8a0e5`，浅色 `#9146a5`。深色背景 `#19151e`、玻璃 `rgba(21,14,28,.66)`；浅色背景 `#faf6fc`、玻璃 `rgba(255,249,255,.66)`。光晕在紫/粉之间，正文中性色带轻微紫色。绿色/金色/红色保留业务语义。主题名称「兰紫夜幕」「兰紫晨光」。

透明度与模糊独立可调：`--glass-opacity`、`--blur-glass`。CSS主题由 `data-theme` 控制，密度由 `data-density` 控制。外观持久化与业务数据独立。默认20px模糊、66%不透明度、普通密度；背景图片为原站来源WebP，不把游戏背景当作自有品牌素材。

手机390×844采用抽屉导航，关闭时不可聚焦；胶囊页签和表格各自在内部滚动，整页不横向溢出。主要操作保持可见，弹层可滚动、键盘焦点受控。常用桌面核验1440×1000。

## 论坛迁移方式

复用外壳、tokens、组件节奏、主题与外观控件；以论坛的板块/主题列表/帖子详情替换 GM 角色身份与领域表单。保留独立路由、认证、数据模型和部署。不要复制 GM 凭据、玩家资料、数据库代码或演示存储键。

第一版 `gm-web/` 和历史86jp候选均为封存历史，不作为视觉来源。用户明确不接受验收时重新出现老版 UI。设计变更以冻结样式及布局规则为基准对照；业务需要可调整具体控件，但保持布局与主题。
